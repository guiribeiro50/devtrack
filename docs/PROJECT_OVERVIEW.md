# DevTrack

## Overview

DevTrack is a full-stack project management platform
designed for software developers and development teams.

## Main Goals

- Manage software development projects.
- Organize tasks using Kanban boards.
- Collaborate with other developers.
- Integrate with GitHub repositories.
- Analyze team productivity.

## Technologies

- TypeScript
- React
- Node.js
- Express
- PostgreSQL
- Prisma
- Docker

## Project Status

Currently in development.
